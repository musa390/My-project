# LUXE PERFUME — Admin Frontend

**Phase 3 status:** In progress — initial Next.js scaffold, shared admin shell, dashboard and demo-only sign-in placeholder added.

## Stack
- Next.js 15.5.29 App Router
- React 19.1 + TypeScript 5
- Tailwind CSS 4
- lucide-react

## Run locally
```bash
npm install
npm run dev
```
Open `http://localhost:3000`.

## Boundaries
- Separate app; do not place Admin pages in `customer-frontend/`.
- Dashboard values are illustrative demo data, not live metrics.
- Sign-in is a disabled placeholder. No authentication, API or database is connected.

## Planned modules
Dashboard, Products, Categories, Orders, Customers, Inventory, Promotions/Coupons, Reviews, Reports/Analytics, Admin Profile and Settings.
