# Database Design — Pending

The relational ERD and schema will be designed in Full-Stack Phase 4. Candidate domains include users/roles/permissions, products/categories/brands/collections/images/variants, carts, wishlists, addresses, orders/order items, payments, inventory, coupons, reviews, banners, newsletter subscribers and contact messages.

These are planning candidates, not an approved final schema. Define keys, cardinalities, uniqueness, deletion rules, indexes, monetary precision and status transitions before writing migrations. The authoritative Flyway migration files will live in the Spring Boot backend resources.
